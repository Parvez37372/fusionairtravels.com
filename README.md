✈️ FusionAirTravels.com
FusionAirTravels is a full-featured online travel booking system offering flights, hotel reservations, and holiday packages. This project includes both a User Interface for travelers and an Admin Panel for travel agency staff.

🌐 Live Website
https://fusionairtravels.com

🧭 Features
🧑‍💼 Admin Panel
Admin login authentication

Manage flights, hotels, and packages

View and manage bookings

User management

Content management (banners, FAQs, etc.)

Dashboard with analytics

🧳 User Side
User registration/login

Search and book flights or hotels

View upcoming and past bookings

Pay online (via Razorpay, Stripe, etc.)

Support & contact form

🏗️ Tech Stack
Layer	Technology
Frontend	HTML, CSS, JavaScript, Bootstrap
Backend	PHP / Node.js (choose based on actual)
Database	MySQL / MongoDB
Hosting	cPanel / VPS / Shared Hosting
